# Research Lit Tool

A tool that helps organize, summarize, and search research papers on a given topic.
Built as a collaborative project combining a technical/software perspective with
subject-matter expertise from a medical student-researcher.

## What it does
- Extracts text from research papers (PDF or abstract)
- Generates structured summaries (objective, method, sample size, key finding, limitations)
- Categorizes papers by theme or method for easy browsing
- Provides search/filter across a collection of papers
